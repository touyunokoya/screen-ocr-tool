# 画面OCRツール(日本語・英語・数式対応)/ Screen OCR Tool

画面の好きな部分をドラッグで囲むだけで、**日本語・英語・数式(LaTeX)** をテキスト化して
メモファイルに自動追記+クリップボードにコピーする、Windows用の常駐ツールです。

**完全無料・オフライン動作**(初回セットアップ後はネット接続不要)。

![デモ: Ctrl+Shift+A で範囲選択すると数式込みでテキスト化される様子](assets/demo.gif)

## 特徴

- **Ctrl+Shift+X** — 文章モード(日本語+英語、一瞬で認識)
- **Ctrl+Shift+Z** — 数式モード(数式1つをLaTeXに変換)
- **Ctrl+Shift+A** — 混在モード(論文の段落など、文章+数式をまとめて高精度認識)
- 認識結果は `memo.md` に日時付きで自動追記、同時にクリップボードへコピー
- **PDF丸ごと変換**(任意インストール) — 論文PDFを数式LaTeX付きMarkdownに一括変換
- NVIDIA GPUがあれば自動で高速動作(なくてもCPUで動作)
- GPUメモリが逼迫すると自動でメモリを解放(ゲームとの共存)

## 類似ツールとの違い・使い分け

画面のテキスト化には優れた先行ツールがあり、本ツールもそれらから多くを学んでいます。
それぞれ設計思想が異なるので、正直な比較と使い分けの目安を載せておきます。

|  | Snipping Tool / PowerToys (Microsoft) | Mathpix Snip | 本ツール |
|---|---|---|---|
| 料金 | 無料 | 無料枠あり / Pro 月$4.99〜 | 無料・無制限 |
| 文章OCR(日本語) | ✅ 手軽で高速 | ✅ | ✅ 同エンジン+誤認識の自動補正 |
| 数式 → LaTeX | — | ✅ **業界最高水準** | ✅ 標準的な印刷数式なら実用十分 |
| 文章+数式の混在認識 | — | ✅ | ✅ |
| PDF丸ごと変換 | — | ✅(枠制限あり) | ✅ 無制限(任意インストール) |
| **手書き数式** | — | ✅ **得意** | ❌ 印刷された数式のみ |
| 結果の自動蓄積 | クリップボードのみ | アプリ内履歴 | ✅ 手元の `memo.md` に日時付き追記 |
| 通信 | オフライン | クラウド送信 | ✅ **完全オフライン** |
| スマホ対応 | — | ✅ | ❌ Windowsのみ |
| カスタマイズ | — | — | ✅ コード公開・改変自由 |

### 使い分けの目安

- **たまに普通の文章をコピーしたいだけ** → OS標準の Snipping Tool が最も手軽で確実です
- **手書きノートの数式化、スマホでの撮影、最高精度が必要** → Mathpix Snip が最良の選択です。
  数式OCRの完成度は業界の到達点であり、本ツールが目標にした存在でもあります
- **印刷された論文・資料から、日本語文章と数式を日常的に大量に取り込む** → 本ツールが向いています。
  回数無制限・完全オフラインなので、未公開の研究資料やコストを気にせず使えます

### 本ツールの設計思想

「数式を含む文献を毎日読む学生・研究者が、回数とプライバシーを気にせず使える道具」を目指し、
優れたオープンソースAI([Surya](https://github.com/datalab-to/surya)・
[Marker](https://github.com/datalab-to/marker)・
[RapidLaTeXOCR](https://github.com/RapidAI/RapidLaTeXOCR))と
Windows標準OCRを組み合わせて、すべての処理を手元のPCで完結させています。
これらの素晴らしいプロジェクトの作者の方々に感謝します。

## 動作環境

| 項目 | 条件 |
|---|---|
| OS | Windows 10 / 11(日本語版) |
| ディスク空き | 8GB程度 |
| GPU | NVIDIA製を推奨(なくても可。混在モードのみ低速になります) |
| ネット接続 | 初回セットアップ時のみ必要 |

## インストール

1. このフォルダ一式をPCの好きな場所に置く(例: ドキュメント内)
2. **`setup.bat` をダブルクリック**(青い画面が出て自動で進みます。10分前後)
   - Pythonが無ければ自動インストールされます
   - NVIDIA GPUの有無も自動判別されます
3. 完了したら **`start_ocr_tool.vbs` をダブルクリック**で起動
   - 初回起動時のみAIモデル(約1.7GB)が自動ダウンロードされます
   - 画面右下に青い「字」アイコンが出たら準備完了

詳しい使い方は [使い方.md](使い方.md) を参照してください。

## 使用している技術

| 認識対象 | エンジン |
|---|---|
| 日本語・英語の文章 | Windows標準OCR |
| 数式 → LaTeX | [RapidLaTeXOCR](https://github.com/RapidAI/RapidLaTeXOCR) |
| 文章+数式の混在(高精度) | [Surya OCR](https://github.com/datalab-to/surya) |

Python / tkinter / PyTorch(CUDA) / ONNX Runtime / マルチスレッド常駐設計
